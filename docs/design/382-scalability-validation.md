# 请求观测与统计验收报告

本文对应 [当前设计](382-scalability.md)，仅记录有效验证结果、适用范围与待完成项。功能测试和常用统计查询采样有通过证据，完整容量与真实页面验收尚未完成；不能据此认定整体交付或生产性能全部达标

## 实现与验收范围

| 范围 | 当前状态 |
| --- | --- |
| 源表 | JSON 按依赖校验，历史引用与冻结快照独立于当前配置，恢复租约单独存储 |
| 用量与账本 | Token 方向命名贯穿存储与管理接口；费用事件按 Key 索引，预算窗口按实际滚动条件更新 |
| 统计 | 窄事实、两级持久队列、十五分钟／小时汇总、日级排名计数及可恢复构建状态 |
| 查询与缓存 | 一致性快照、互斥桶合并、有界事实回退、同键刷新合并和删除失效 |
| 页面 | 保留业务指标和失败提示；统计元数据及分组 ID 筛选供接口使用，不提供额外状态行、说明图标或分组输入框 |
| 界面缺陷 | 使用统计刷新后向上移动的问题尚未定位和修复 |

性能判断使用当前实现的绝对延迟、正确性与资源成本。短轮样本不证明稳定尾延迟，未执行场景不计为通过；不采用新旧实现相对增幅作为本报告的验收结论

## 数据完整性

620 万行合成库回填验证中，源请求与窄事实均为 `6,206,452` 条，两级待处理队列为空。没有固定单一构建的完整回填吞吐结果，分段推进耗时不作为生产周期吞吐

24 小时与 30 天范围的请求数、成功／失败／取消数、六项 Token 总量及两种 USD 情景金额均与独立源表查询相等。确定性抽样 1000 个请求 ID、逐项比较 43 个源／事实字段，无缺行或差异

日级排名计数与小时计数对账零差异；56 组固定范围结果一致，覆盖排名、计数、Token、费用与分位数。结果一致性不代替完整大库 Top N 独立真值对账和分位数误差验收

数据面短轮包含 30 次正式请求和 10 次预热，全部完成，40 条源记录、事实与日级排名贡献一致，两级队列为空，未观察到观测丢弃或落库失败。该结果验证当前计数维护链路，不代表持续写入吞吐或稳定请求 P95

## 查询性能

Store 覆盖 24 小时／30 天各 15 类查询，每类两次，共 60 次。58 次返回完整结果，两次因分组 OR 匹配 `117,856` 条超过 `100,000` 行预算而明确拒绝，没有超时

| 30 天 Store 查询 | 两次样本耗时 |
| --- | --- |
| 全局统计 | 188～535 ms |
| 账号 Top 100 | 767～1339 ms |
| Key Top 100 | 617～1036 ms |
| 单分组 | 754～1206 ms |
| 分组 OR 超预算拒绝 | 600～601 ms |

Admin HTTP 覆盖 24 小时／30 天、8 类接口，包含单分组。每组使用两次不同范围的串行冷／热请求和四并发同范围冷／热请求，共 192 次，全部成功。四并发同键测试用于验证刷新合并，不代表四个不同范围同时聚合

各组样本 P95 符合冷 2 秒／热 500 ms 目标，最高约为 1787 ms／74 ms。30 天串行冷样本 P95：全局 587 ms、账号 958 ms、Key 1787 ms、分组 1241 ms。每组样本有限，不能作为稳定尾延迟或冷磁盘性能的证明

查询预算保持十秒，窄事实合并预算保持十万行。预算拒绝、依赖错误与超时分别统计，不截断结果或只计算成功样本来宣称通过

## 详情存储与空间

当前大诊断详情使用 TOAST，不设置独立详情表。10 万条、每场景三次的隔离对照中，内容一致且无残留租约；分表未呈现一致的读取收益

| 指标 | 请求表内字段与 TOAST | 独立详情表 |
| --- | ---: | ---: |
| 装载后总空间 | 1,664,172,032 B | 1,675,386,880 B |
| 1000 条终态与详情写入中位数 | 597.85 ms | 623.95 ms |

独立详情表方案的该写入阶段集群 WAL 约高 3.1%。结论限于这组样本，不表示所有负载下 TOAST 都更优，也不构成百万行详情或稳定保留期容量验收

日级窄计数样本为 620,168 行、116,408,320 B，约 111 MiB。高基数完整指标汇总仍有显著空间成本；全量源表、TOAST、索引、租约、事实、汇总与队列的稳定容量预算尚未完成。生产可回收字节数未测定，不以死元组比例替代空间证据
