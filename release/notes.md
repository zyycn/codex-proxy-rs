# v3.55.1

## 优化改进

- 统一各页面的平台选择器，分组和密钥按平台展示专属配置，通用项保持独立
- 工作区匿名化拆分为项目名、用户名、Git 远端及提交信息四个可编辑步骤，已有组合规则继续生效
- 更新 macOS 客户端身份预设，CLI 预设默认使用 TUI 入口和 Apple Terminal，保留已保存的入口与终端配置

## 问题修复

- 修复 OpenAI、xAI 和 Antigravity 的账号后台操作未使用全局上游身份的问题，覆盖 OAuth、令牌续期、额度刷新及目录查询等场景
- 修复插件 SDK 未同步项目匿名化动作的问题，使其与宿主隐私配置合同保持一致
