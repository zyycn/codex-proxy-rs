# v3.45.0

## 新增功能

- Anthropic Messages：支持 `/v1/messages` 普通和流式请求，API Key 账号可选择 Messages 上游，与 Responses、Chat Completions 客户端互通
- Messages 输入计数：`/v1/messages/count_tokens` 对 Anthropic 官方上游使用原生计数，其他上游使用本地估算
- OpenAI OAuth 账号：可为通用额度窗口设置使用率上限，任一窗口达限即暂停接收新请求，在途请求继续
- 主动额度重置卡：除默认的临期使用外，可在剩余周额度降至指定比例时自动用卡，未填比例时等周额度耗尽再用
- 插件 SDK：可指定客户端密钥日预算和周预算的起止时间，窗口外拒绝新请求，到期不自动续期

## 优化改进

- Codex 接入：「使用密钥」生成的配置默认开启 API Key 模型发现
- 账号预热：五小时窗口使用率为 0% 或缺少活跃证据时允许轻量预热，无需额外查询额度
- 用量诊断：错误详情区分 HTTP 响应与 WebSocket 错误，并提示尝试记录是否可能缺失
- 账号并发详情：请求较多时表格随行数展开

## 问题修复

- OpenAI 模型目录：合并当前密钥可用账号各自的模型，同套餐中只有部分账号可用的模型也能出现在选择器中
- 用量记录：有明确失败原因的请求显示为失败，结果仍不确定的请求保留为未完成
- CPR 互联：请求回到已经过的部署时停止转发，避免节点间循环调用
- 安全依赖：更新 SQLite 和 OpenSSL 相关依赖，修复已知安全问题

## 升级须知

- 源码部署：已执行原 `0040_account_warmup_cron.sql` 或后续未发布迁移的数据库不能直接升级；请先在独立库验证迁移前的备份，不要手改迁移记录
- 定时账号预热：升级会清空旧计划并关闭预热，保留已选模型；需要继续预热时，请按部署时区填写五段 Cron 表达式并重新启用
- 互联共享范围：共享密钥现在也会使用所选分组中的 API Key 账号，如只想共享 OAuth 账号，请检查分组成员
- 互联部署：转发链上的反向代理须保留 `X-CPR-Route` 请求头；用整库副本搭建独立节点时，请先按[部署说明](https://github.com/zyycn/codex-proxy-rs/blob/v3.45.0/deploy/README.md#cpr-互联)更新新库的部署标记
