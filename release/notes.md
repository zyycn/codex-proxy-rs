# v3.48.0

## 新增功能

- 请求历史：保留期可设为超过 31 天的正整数，默认仍为 31 天，升级保留已有设置
- 管理端：支持在兼容浏览器中安装为独立窗口应用，需通过 HTTPS 或本机回环地址访问，使用时仍需联网

## 优化改进

- OpenAI 客户端画像：无法在线获取版本时，内置 CLI 版本为 0.169.0，macOS 和 Linux Desktop 的 Core 版本为 0.169.0-alpha.11.1，Windows 为 0.167.0-alpha.4.1

## 问题修复

- OpenAI 账号：模型目录刷新、导出、预热和连接测试使用已保存的全局客户端画像，修复选用新版 CLI 后目录仍可能缺少模型的问题
- Responses：HTTP 和 WebSocket 请求通过正文传递安装身份，默认不再额外发送独立的安装 ID 请求头
- WebSocket：下游读取缓慢时，取消请求或关闭连接池仍能及时释放上游连接
- 依赖安全：更新 Quinn 和 rustix，修复依赖审计报告的问题

## 升级须知

- Responses 的 UUIDv7 会话和线程标识、Codex 复合窗口标识在升级后会映射为新值；账号隔离保留，UUIDv7 的原始创建时间和窗口序号对上游可见
