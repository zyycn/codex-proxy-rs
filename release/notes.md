# v3.4.1

## 问题修复

- 修复通过普通 HTTP 访问管理端时，额度重置点击“下一步”因 `crypto.randomUUID` 不可用而无响应的问题；保留请求重试时的幂等标识。
- 修复 Cloudflare Tunnel 等反向代理注入的 `cf-visitor`、`cf-warp-tag-id` 等链路头被透传到上游、导致 HTTP 或 WebSocket 请求遭遇 403 的问题。统一过滤下游传输头与压缩协商，继续保留业务扩展头及上游响应诊断信息。
- `POST /v1/responses` 支持接收 `gzip`、`deflate`（zlib 封装）和 `zstd` 压缩正文，避免将压缩数据直接当作 JSON 而返回 `invalid_json`。
- 加固请求解压的内存边界，支持完整读取 gzip 多成员和 zstd 多帧，拒绝损坏、超限及叠加编码的请求，避免静默忽略后续内容。

## 体验优化

- 账号用量统计优先使用周额度窗口，周窗口不可用时使用月额度窗口；没有符合条件的窗口时，不再回退到短期限流窗口或历史累计值。额度比例和 Dashboard 的窗口选择保持不变。
- Tokens 结构和模型使用排行统一显示“周额度窗口”或“月额度窗口”，并修正汇总数字与窗口标签的水平对齐。

## 升级说明

- 从 v3.4.0 升级无需新增数据库迁移或配置调整。
- 压缩的 Responses HTTP 请求展开后最多为 64 MiB，zstd 解码窗口也限制为 64 MiB；超限或无法满足解码限制的请求会被拒绝。本次不新增未压缩正文或 WebSocket 帧的长度限制。
