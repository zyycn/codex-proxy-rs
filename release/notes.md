# v3.58.0

## 新增功能

- API 密钥可设置生效和到期时间，已有密钥和未设置有效期的新密钥默认长期有效
- 代理管理支持保存自定义 HTTPS 测试目标，可批量查看各代理访问同一站点的状态码和延迟
- 密钥管理页和用量页可生成 OpenAI、xAI 和 Antigravity 的客户端配置，并支持导入 CC Switch

## 优化改进

- 手动重置密钥额度后立即开始新的计费窗口，日额度从重置时起算 24 小时，周额度起算 7 天
- CPR 互联按使用情况刷新上游额度，耗尽账号按重置时间复查
- 账号连接测试支持搜索模型，账号列表可查看被截断的邮箱和备注全文

## 问题修复

- OpenAI 原生续写在原账号排队超时后，若有其他账号可立即接入，网关会提示客户端携带完整历史重发
- Antigravity CLI 独立网页搜索可使用 OAuth 账号目录声明的搜索模型，修复因找不到辅助型号而返回 404 的问题
- 请求记录区分网关选号时的额度耗尽、上游限流及密钥自身的频率和并发限制，便于定位失败原因

## 升级须知

- 已在 PostgreSQL 18 上验证从 v3.57.2 升级。源码部署若执行过开发版的 `0049_client_key_validity.sql` 或 `0050_proxy_test_targets.sql`，直接升级会在启动时迁移校验失败
