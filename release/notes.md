# v3.59.0

## 新增功能

- 提示词改写以平台和规则名称列表管理，支持弹窗编辑、按上游限定首个前缀替换，空替换可删除前缀，输入计数同步应用规则

## 优化改进

- 请求记录优先显示错误码，并按界面语言展示常见错误原因，区分上游容量不足、连接关闭与请求受限
- 管理端升级至 UI v0.13.6，改善深色分段选择器的选中状态、多选标签底色，以及可搜索单选框的对齐、字重和加载提示
- 密钥额度对齐的参考账号统一显示账号名称或邮箱，避免重复展示邮箱

## 问题修复

- 多行输入框自动高度正确遵循最小和最大行数，内容减少后可收缩
- 多个弹窗同时打开时，关闭或卸载较早打开的弹窗不会提前解除页面滚动锁

## 升级须知

- Antigravity 普通 Chat 转发不再自动前置客户端画像提示词；需要改写系统指令时使用通用设置中的提示词改写规则，原生生成与计数仍前置画像提示词
- 已在 PostgreSQL 18 上验证从 v3.58.0 的数据库结构升级，现有运行设置保持不变，提示词改写规则默认为空
