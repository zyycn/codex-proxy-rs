# v3.46.0

> [!IMPORTANT]
> **出站代理规则已统一。** 账号请求、插件受管网络和网关下载优先使用显式指定的代理。账号未绑定代理或绑定的代理已禁用时，使用「部署默认出口」
>
> 默认出口按目标协议读取网关进程的环境变量：HTTP/WS 使用 `HTTP_PROXY`，HTTPS/WSS 使用 `HTTPS_PROXY`，未设置对应变量时使用 `ALL_PROXY`。命中 `NO_PROXY` 或没有适用的环境代理时直连；选中的代理连接失败会报错，不会回退直连
>
> 如果网关已设置环境代理，升级前请检查原先依赖直连的目标是否已列入 `NO_PROXY`。使用 Docker Compose 时，环境变量应配置在网关服务的 `environment` 中，修改后需重新创建容器

## 新增功能

- 智能调度：可分别设置 5 小时、周、月额度重置对选号的影响，例如只优先选择周额度即将重置的账号

## 问题修复

- OpenAI WebSocket：按上游连接声明的消息大小上限发送请求，避免大请求过早切换到 HTTP；仅能在原连接续写的请求超限时，提示客户端重发完整历史
- 系统更新：修复 macOS 和 Linux 移动只读目录时可能导致的更新或回滚失败，保留目录原有权限
- 管理界面：切换主题预设时保留自定义功能色、背景色和文字色

## 升级须知

- 原有智能调度配置的三个重置窗口系数默认为 0；此前依赖额度重置评分的部署，请至少为一个窗口设置正系数
- 发往 OpenAI Responses 上游的生成请求会忽略客户端指定的输出 Token 上限，实际输出可能超过该值；OAuth 和 API Key 账号均适用
