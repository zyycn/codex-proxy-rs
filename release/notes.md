# v3.41.0

## 升级事项

- 从 v3.40.0 升级没有新增数据库迁移
- 管理 API 的账号模型用量会返回仅有失败记录的模型；没有成功用量时，`lastUsedAt` 为 `null`，没有有效健康样本时，`successRate` 为 `null`
- 更改或清除 Key 的安装 ID 覆盖，若生效 ID 随之变化，已有 WebSocket 续接需重新发送完整上下文

## 账号、代理与密钥

- 修复账号展开后的模型成功率始终显示 100% 的问题。成功率按成功、服务失败和未完成请求计算，排除取消、调用方 4xx 和已恢复的中间记录；仅失败时显示 0%，无有效样本时显示 `—`。调用数、Token、费用和最近使用时间仍只统计完整交付的成功用量
- 账号创建、编辑和批量编辑支持测试直连或已保存代理的出口，显示耗时及 IPv4 / IPv6。禁用代理时按实际直连出口测试，批量“保持当前”时禁测；出口测试不保存账号设置，也不验证账号权限或额度
- 代理的“关联账号”弹窗支持搜索、跨页多选并批量分配账号，一次最多 1000 个。分配会替换所选账号的原代理，保留凭据、分组与调度设置
- 客户端 Key 可单独配置或生成 OpenAI 安装 ID，同时继承全局 UA。留空时沿用账号安装身份；固定后，换账号仍使用该 ID
- 上游明确关闭共享或不支持 CPR 互联时，账号恢复显示为普通 API Key；临时失败保留已有识别结果。可通过“刷新额度”重新识别互联

## Chat Completions 与 Responses

- 扩展 Chat 的 function/custom 工具调用与结果往返、文件和音频输入，以及 Responses 原生参数映射。同语义字段交给 Provider 和上游判断；`stop`、`seed`、penalties 等无对应 Responses 控制语义的参数接受后忽略，不保证生效。无法保留输入、客户端动作或续接语义的请求仍明确拒绝
- Chat 的 JSON/SSE 响应保留公开推理、图片结果、logprobs、结构化引用和实际 Token 明细。推理与图片字段属于网关扩展，需要客户端支持；推理及压缩密文不作为可读正文返回，搜索与其他工具仍需分开请求
- 修复完整历史请求因缺少本地归属记录而丢失 `x-codex-turn-state` 的问题，覆盖 HTTP 和 WebSocket。明确换号或可信续接状态表明已换轮时仍清除该值，不改变 response ID 的续接授权边界

## 诊断与管理界面

- 数据面 HTTP 的鉴权、解码、未知路由、方法错误及执行前中间件失败记录为运维错误，可按入口 ID 查询，不伪造模型请求或用量
- 显式开启 `request_dump` 后，按实际消费过程捕获入口请求与响应的原始头和正文，标注未消费或读取失败的不完整转储。该开关默认关闭，转储包含凭据与用户内容，仅用于受控排障
- 调整模型访问、插件安装和错误保护表单的校验时机，避免切换模式或新增未填完的配置时立即报错。修复移动端登录表单居中，精简重复提示与错误文案
