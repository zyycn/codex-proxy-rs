# v3.39.1

## OpenAI 兼容性

- 修复同轮全量请求丢失 `x-codex-turn-state` 的问题：HTTP 与 WebSocket 请求可回传已确认归属的上游轮次 token，包括失败响应中收到的值；继续隔离不同 Client Key、账号、会话、线程和轮次，不放宽其他续接状态的校验
- 保留客户端的 `traceparent`、`tracestate`、`sentry-trace`、`baggage` 及对应 WebSocket metadata，`x-openai-fedramp` 按业务头原样透传并保留多值
- 出站 `x-codex-installation-id` 使用所选账号的持久安装身份，与正文中的安装身份一致；地域与账号路由头继续由部署配置控制，配置值覆盖客户端同名头，省略或 `null` 时不发送

## 运行稳定性

- 配置提交发生版本竞争时，在既有有界重试预算内重新读取完整快照并准备扩展，减少创建或撤销 Key 等并发操作造成的短暂不可用；持续竞争或真实存储、扩展故障仍按原有规则暂停快照
- 修复删除代理返回版本冲突后事务锁未及时释放的问题，避免阻塞紧接着的代理编辑或删除

## 代理检测

- 双栈代理的延迟按首选可用出口的 HTTP 探测耗时显示，IPv4 优先，其次 IPv6，不再把另一地址族失败的等待计入成功出口延迟；检测仍等待两个地址族完成或超时，以保留完整可用性结果
