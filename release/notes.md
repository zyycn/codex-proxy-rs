# v3.5.0

## 新增功能

- 账号用量面板新增周/月额度容量预测，可查看预计 Token、等价 USD 费用、源窗口剩余估算及采样依据；支持周/月切换和刷新额度后重新采样。
- 预测优先使用近期额度进度分段，明确提示样本不足、记录缺失和周期折算；Token 与费用分别判断完整性，缺失数据不按零消耗外推。

## 问题修复

- 修复 Codex 模型目录将默认上下文窗口误作最大窗口的问题，分别保留上游 `context_window` 与 `max_context_window`，缺失值不再自行补齐。
- 完善 HTTP 与 WebSocket 错误的上游状态、结构化原因及请求 ID 关联，避免失败信息被通用文案覆盖或关联到错误的请求。
- 补记已进入模型执行、但尚未建立上游流时的无可用账号、准备失败、超时和取消，便于通过网关请求 ID 排查；没有实际尝试时不虚构账号或上游调用。
- 修复请求记录无法按账号邮箱与名称搜索的问题，按请求发生时的历史快照进行字面量前缀匹配；完整 Client Key 搜索仅提交可见前缀。
- 保留令牌刷新等管理操作中可安全展示的具体原因，区分账号繁忙、上游明确拒绝和刷新结果未知，避免将上游认证失败误作管理员会话失效。
- 修复运行时快照并发刷新可能被旧结果覆盖、取消后的执行清理未能持续完成，以及账号展开行重建后丢失额度重置未决状态的问题。

## 体验优化

- 管理端统一展示接口安全错误消息，减少重复弹窗；取消请求与静默后台请求不再产生普通错误提示，批量操作仍保留汇总反馈。
- 用量与错误查询统一刷新、筛选和分页快照行为；诊断反馈包改为仅导出允许的关联、分类、阶段与计时信息，并加强未知 JSON 内容的诊断脱敏。
- 账号导入和 OAuth 完成（含重新授权）在提交后后台读取一次额度，不再等待该次观测才返回成功；观测失败不回滚账号。

## 升级说明

- 从 v3.4.1 升级无需新增数据库迁移或配置调整。
- 额度预测依赖本地用量与上游额度观测，仅供参考，不参与调度或账单结算；剩余估算对应额度快照时的源窗口，不是实时余额，等价 USD 也不是官方订阅价格。
- 部分令牌刷新失败的管理接口业务码调整为 `50201` 或 `50202`（HTTP 502）。自建管理客户端应保留具体错误消息；结果未知时先核对账号状态，不要自动重放可能已经轮换的一次性刷新令牌。
- 诊断反馈包使用 `schemaVersion: 2`，不自动包含原始错误正文、请求响应头或完整 trace data；旧诊断记录不清理或回填，分享历史材料前仍需审阅脱敏。
