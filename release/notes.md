# v3.39.0

## Windows 支持

- 新增 Windows x64 与 ARM64 发行包，静态链接 MSVC 运行库，解压后无需额外安装 VC++ Redistributable
- 支持 Windows 管理端在线更新、重启与回滚，处理运行中程序替换、重启交接及只读发行文件清理，并校验 Windows 特有的不安全归档路径
- 补充 Windows 二进制部署说明；运行前需准备 PostgreSQL 和 Redis，使用数据库备份时需提供匹配服务端版本的 `pg_dump`

## 插件设置

- 敏感配置支持逐字段修改，补填一项不会清除其他已保存密钥；留空保留现有值，单项清除可在保存前撤销
- 设置弹窗直接展示各敏感字段的保存状态，支持清理目标版本不再使用的字段，并调整表单与 JSON 切换按钮的尺寸

## 互联与部署

- 请求记录、Dashboard 最近请求和账号维度诊断补充 CPR 互联徽标，按账号当前互联摘要展示，不改写请求历史快照
- 补充小内存部署的 PostgreSQL 预算、应用连接池和 Redis 持久化调优说明，包含生效、验证与回退步骤；默认配置保持不变

## 升级事项

- 插件管理 API 的 `secrets` 改为逐字段更新：字符串设置对应值，`null` 清除对应字段，未出现的字段保留；省略 `secrets` 或传 `{}` 均不修改密钥。依赖整份替换或空对象清空语义的调用方需调整
- 跨插件版本编辑优先使用目标版本保存的密钥快照，没有快照时沿用当前值，再应用本次字段变更
- Windows 首次部署请下载对应架构的完整发行包；插件安装包须匹配宿主系统与架构，部署前需验证实际插件运行与上游调用
