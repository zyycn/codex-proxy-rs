# v3.41.2

## OpenAI 账号模型白名单

- 修复原生 Responses 请求被模型目录拦截的问题。OpenAI OAuth 或 API Key 账号的白名单精确包含映射后的上游模型 ID 时，即使目录尚未收录，也会允许该账号向上游请求，由上游确认是否可用
- 升级后已有白名单自动生效。目录外模型的放行只对配置该 ID 的账号生效，混合号池中的其他账号仍按各自的模型限制和有效目录选号

## 管理端

- 编辑账号时分组展示自定义模型和上游目录。搜索到已有模型时可直接勾选，输入未匹配的有效 ID 时可点击「添加模型」或按回车添加。全选和取消全选只作用于当前搜索命中的上游目录项
- 账号连接测试可以选择白名单中的自定义模型，方便验证指定账号能否实际调用该模型
- 请求健康卡片分别展示已取消和未完成的请求数。悬停图表可查看对应时段的服务成功率，缺少有效样本时显示「无有效样本」
