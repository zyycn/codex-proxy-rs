# v3.54.4

## 问题修复

- OpenAI Responses 经 WebSocket 上传长会话时，若上游在首条响应文本前因请求过大关闭连接，允许回退的请求会通过同一账号改走 HTTP/SSE
- Codex 切换 `x-codex-exclude` 响应字段设置后，WebSocket 按新设置选择连接，依赖旧连接的续接会提示客户端重放完整历史
- 严格账号亲和下，聊天主账号缺少生图资格时，主会话和子会话可临时借用有权限的账号生成或编辑图片，后续聊天继续使用原账号
- 导入 OpenAI API 密钥账号时，只需在账号设置中填写一次名称，手动导入时留空会使用「密钥账号」
- 将后端 `url` 依赖升级至 2.5.9，修复安全公告 `RUSTSEC-2026-0592` 所列问题
