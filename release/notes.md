# v3.6.0

## 新增功能

- 创建客户端密钥时支持填写自定义 Key，便于沿用旧平台凭据；留空仍自动生成。自定义值支持不同前缀、长度和标点，沿用本平台的分组权限、限额与并发规则。
- 密钥列表、请求记录和错误列表支持按密钥名称搜索；创建和修改名称时校验重名，忽略大小写和首尾空白。

## 问题修复

- 修复 Codex 模型目录丢失原生元数据的问题，完整保留上游提示词、工具能力、上下文窗口及 `service_tiers`，使支持的客户端可按上游声明显示 `/fast` 等服务档位。目录遵守密钥的账号范围，模型别名保留目标模型的完整元数据。
- 修复同源 HTTP 管理端无法保持登录及复制失败的问题；会话 Cookie 随浏览器来源区分 HTTP 与 HTTPS，HTTPS 反向代理使用 HTTP 回源时仍保留安全属性。
- 将 OpenAI 的 `generate: false` 预热请求排除出推理用量和额度预测统计，保留审计记录与额度观测，避免预热记录干扰预测；预测面板使用实际额度观测时间。

## 体验优化

- 精简额度预测面板，聚焦容量与剩余估算，减少采样明细和重复提示。
- 精简请求诊断面板，缺少时间线时使用空状态展示，保留诊断包导出。
- 简化部署初始化命令，合并目录创建、配置复制和权限设置。

## 升级说明

- 从 v3.5.0 升级时，服务启动自动执行 `0006_custom_client_keys.sql`，保留已有密钥；无需新增配置项。历史重名密钥仍可使用，再次保存时需调整为未被占用的名称。
- 密钥相关搜索不再匹配 Key 值或可见前缀，请改用密钥名称；请求记录仍支持按 Client Key ID 查询。
- 额度预测管理接口移除了 `generatedAtDisplay`、`method` / `methodDisplay` 及部分采样诊断字段。自建管理客户端需按 [当前 API 合同](https://github.com/zyycn/codex-proxy-rs/blob/v3.6.0/docs/api.md#周月额度预测) 调整。
- Codex 客户端需重新加载模型目录，才能取得更新后的服务档位与能力信息。
