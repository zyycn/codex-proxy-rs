# v3.42.1

## 新增功能

- 插件管理页：打开外部链接前显示目标域名，可选择打开、复制链接或取消

## 优化改进

- OpenAI 调度：因账号队满或超时而换绑会话时，诊断记录会显示原因及换绑前后的账号

## 问题修复

- 账号授权：修复使用设有 WebSocket 连接上限的已保存代理时，OpenAI 或 xAI 授权回调被误判为代理配置已变更的问题
- Codex 选模：上游只返回模型 ID 时，默认列表隐藏已识别的生图、实时和语音合成模型，仍可按 ID 直接调用
- 管理端：改善下拉菜单与浮层的定位和切换效果

## 升级须知

- 使用已保存代理且 WebSocket 连接上限非零时，升级或回退后请重新发起尚未完成的 OpenAI 或 xAI 授权；已保存的账号和凭据不受影响
- 自定义更新仓库：新版从 `main` 分支的 `release/version.yaml` 读取 `published` 通道表，发布工作流需要写入 `main` 的权限
