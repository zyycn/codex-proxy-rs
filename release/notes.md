# v3.6.1

## 问题修复

- 周/月额度预测不再因个别请求缺少 Token 或费用记录而整体不可用，继续使用已记录数据估算容量与剩余量。对应数据完全缺失时仍保留未知状态，不补算为零。
- 将“数据不完整，暂时无法预测”提示改为估算精度说明，提示漏记或失败请求的消耗可能使结果偏低。
- 清理官方已关闭的 OpenAI 模型计价规则及旧别名；仅宣布弃用、尚未到关闭日期的型号继续保留计价。

## 升级说明

- 从 v3.6.0 升级无需新增配置或数据库迁移。
- 历史费用总额保留，不重新计价；已移除计价规则的型号无法再补充历史费用拆分。现役模型的常规价格及 GPT-6 Astra 计费公式不变。
