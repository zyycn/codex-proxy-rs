# v3.51.0

## 新增功能

- 插件可按账号、额度桶和时间范围分页读取已保留的 OpenAI 请求额度观测及区间起点基线，单次查询区间最长 366 天
- 调度插件可区分候选账号的会话绑定、优先选择、跟随绑定和固定选号关系

## 优化改进

- 账号、Key 和代理的更多操作菜单支持统一的键盘交互
- 额度设置在提交时校验并定位错误，预热开关与额度桶标题同行显示
- Key 用量页缩窄桌面端模型筛选框

## 问题修复

- OpenAI 严格亲和下，子线程因绑定账号的模型权限受限而等待换号时，超时提示明确说明模型限制

## 升级须知

- 调度插件的 `scheduler` 能力升级至 v4，使用 v3 的插件需更新能力声明并适配新增候选字段后使用
- 历史额度查询受请求记录保留范围限制，使用观测差值时需处理重置、套餐变化和缺样
