# v3.45.2

## 优化改进

- Codex 接入：「使用密钥」生成的配置默认开启异步上下文压缩，该功能在客户端仍处于开发阶段
- 管理界面：修正表单帮助按钮与标签的对齐，简化排队换号、重试等待和英文提示说明

## 问题修复

- 模型目录：Responses API Key 上游按 Codex 版本协商目录，级联 CPR 时保留上游声明的思考档位
- 轮询调度：仅在成功分配账号时推进轮询，已有会话的亲和命中不再影响新会话的账号顺序
- 上游重试：收到 `NO_MORE_RETRY` 后停止重试当前账号，按现有规则换号或返回上游错误
- 服务档位：原生 Responses 请求保留显式 `auto/default`，避免出站时丢失客户端或分组策略指定的档位
- 用量记录：记录 Messages 请求显式设置的 `output_config.effort`，未设置时保持未知
- CPR 互联：仅向已识别的互联节点发送路由路径头，普通模型上游不再收到该头

## 升级须知

- 互联防环依赖节点完成识别且中间代理保留 `X-CPR-Route`；插件自行转发或改写出站目标时，需自行维护互联路径并在最终模型上游前移除该头
