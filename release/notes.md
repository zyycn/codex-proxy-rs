# v3.41.1

## 升级事项

- 从 v3.41.0 升级没有新增数据库迁移
- 管理 API 的请求健康 `successRate`、健康时间点 `errorRate` 和热点诊断 `errorRate` 在没有有效样本时返回 `null`，接入这些字段的客户端需支持空值

## 请求统计与管理界面

- 首页趋势、请求健康与热点诊断统一错误口径：服务失败与未完成请求计入错误，已恢复记录、客户端取消和调用方 4xx 不参与成功率计算，修复取消请求的 499 被误计为调用方失败的问题
- 无有效样本时显示“无样本”，成功率趋势保留断点，避免把缺少数据显示为 0%；热点诊断同步显示错误数与错误率
- 账号模型目录中被截断的模型名称支持悬停查看完整内容，便于区分长名称模型

## OpenAI 连接与授权

- 绑定的上游 WebSocket 关闭或失效后，网关在完成结算且下游空闲时以关闭码 1000 提示客户端重连并发送完整输入；保留已接收请求的处理顺序，启用 WS 帧中间件时保留连接
- OpenAI OAuth 授权码交换区分连接超时、其他连接失败与授权结果未知，提供对应提示并保留脱敏诊断原因；结果未知时仍需先核对账号状态，避免立即重复提交授权码
- 授权码交换与令牌刷新的连接超时延长至 30 秒，单次请求总超时延长至 60 秒

## 启动与重启

- 启动时使用本地版本进行插件兼容检查，不再等待远端发行查询
- 二进制部署在旧服务释放资源后启动替换进程，减少 Unix 平台重启时的固定等待
