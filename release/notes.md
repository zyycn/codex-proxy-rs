# v3.47.0

## 新增功能

- 账号预热：支持配置多条独立 Cron 规则，分别安排预热时间，同一分钟命中多条规则也只执行一次

## 优化改进

- 用量统计：减少分组重算的临时文件写入
- 统计任务：可通过 `store.pool.analytics_projection_work_mem_mb` 调整增量投影和历史回填事务的工作内存，默认沿用 PostgreSQL 设置

## 问题修复

- OpenAI 模型调度：目录刷新期间或刷新失败后保留最近一次成功目录的排除规则，避免选中不支持目标模型的账号
- 管理界面：恢复主题预设的页面、卡片和浮层底色，保留自定义背景及功能色

## 升级须知

- 原有单条预热配置可直接沿用，API 中的多条规则以半角分号分隔，总长度含分隔符不超过 255 字节
