# v3.53.1

## 新增功能

- 请求记录支持按上游响应、代理处理、上游连接或未知来源筛选错误，可与账号、密钥、模型和时间范围组合使用
- OpenAI Responses 可通过 `openai.ws_pool.fast_path_budget_ms` 调整回退 HTTP 前等待 WebSocket 建连的时间，默认 800 毫秒，可设为 1–15000 毫秒，重启后生效

## 优化改进

- 请求错误表将错误摘要固定在左侧，并单独保存显示列和列顺序
- 管理端操作失败时显示名称重复、数据已更新或凭据需要刷新等具体原因
- 账号列表统一同一订阅套餐的标签配色，长套餐名支持换行

## 问题修复

- 原生 `/v1/responses` 流式请求在发出数据或心跳前收到上游 WebSocket 的普通参数错误时，按上游返回 HTTP 400 并保留原始 `error` 对象
- Codex TUI 连接 Desktop 共享的 App Server 且未单独提供桌面应用版本时，按 CLI/Core 版本校验，避免误用桌面版最低版本限制
- 连续发起账号连接测试时，上一轮测试的延迟回调不会再中断新测试
